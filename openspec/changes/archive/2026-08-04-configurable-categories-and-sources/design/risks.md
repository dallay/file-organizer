| 1 | `Other/` at depth 1 is generated by definition; moving it would create `Other/Other/` (test_14 fails) | exploration esc-6; spec dir-movement/test_14 | `is_generated_category` excludes `Other/` from the source list in `collect_top_level_directories`'s pre-classify. | 2 | Log-file collision: `log_file = "~/Downloads/log.txt"` → log file classified by `.txt` to `Text/` and moved | exploration esc-9, esc-14; spec source-precedence | Canonical log path resolved ONCE in `run`; `skip_paths: HashSet<PathBuf>` passed to BOTH collectors; each candidate canonicalized and dropped on match. | Apply adds a regression test for the collision case. |
| 3 | First-run ordering: `load_config` errors on missing default path, blocking auto-detection | exploration esc-12; spec source-precedence/test_23 | `load_config` stays pure; missing-default branch lives in `src/main.rs:50` and synthesizes `Config::default()` before auto-detect. | test_23 asserts run proceeds with `Config::default()` + detected Downloads. |
| 4 | Explicit `--config /nonexistent` must STILL error (test_24) | spec source-precedence/test_24 | Branch in `src/main.rs:50` matches on `(cli.config.is_some(), config_path.exists())`; only `(false, false)` falls through to `Config::default()`. | 10 | Code-extension set demoted to `Other` | exploration esc-2; explicit user approval in `intent.md:13` ("Code/source files ... map to `Other` (per Option A)") | Documented in README `Default categories`; escape hatch is `[[categories]]` adding a `Code` rule. | README callout; not auto-tested (user-visible config choice). |
