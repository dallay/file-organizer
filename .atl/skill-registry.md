## Compact Rules

- **Rust changes**: Use Rust 2021 conventions; keep CLI parsing in `src/main.rs` and reusable organizer behavior in `src/lib.rs`.
- **Testing**: Add or update a failing unit test before production code. Primary test command is `cargo test`.
- **Formatting/linting**: Use `cargo fmt -- --check`; use `cargo clippy --all-targets --all-features -- -D warnings` when dependencies/toolchain permit.
- **Cross-platform behavior**: Preserve macOS/Linux/Windows compatibility and inspect `platform/` launchers for scheduler changes.
- **OpenSpec**: Store project SDD configuration in `openspec/config.yaml`; never create placeholder specs.
- **Scope**: No repository-specific CI, coverage, or additional skill registry was detected during initialization; the registry is maintained at `.atl/skill-registry.md`.
